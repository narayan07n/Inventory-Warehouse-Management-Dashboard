# Inventory & Warehouse Management Dashboard

## 📌 Project Overview

This project presents an interactive **Inventory & Warehouse Management Dashboard** designed to monitor inventory performance, warehouse stock, purchasing, sales, suppliers, product categories, and low-stock items.

The dashboard transforms raw inventory data into meaningful business insights and provides a centralized view of warehouse and stock performance.

## 🎯 Project Objectives

The main objectives of this dashboard are:

- Monitor overall inventory and stock value
- Track purchased and sold quantities
- Analyze warehouse-wise stock
- Compare supplier-wise purchases
- Identify low-stock products
- Analyze category-wise stock value
- Compare purchase quantity with sales quantity
- Support better inventory and warehouse management decisions
